# 🧮 Exercícios sobre Laços de Repetição e Condicionais

Este repositório contém uma série de exercícios práticos para reforçar o uso de **laços de repetição** (`for`, `while`, `do...while`) e **estruturas condicionais** (`if`, `switch`) em programação.

---

## 📋 Lista de Exercícios

### 1. Tabuada com Verificação de Entrada
- Solicite ao usuário um número entre **1 e 10**.  
- Se o número estiver fora do intervalo, peça novamente (**use `while`**).  
- Imprima a **tabuada** desse número usando **`for`**.

---

### 2. Somatório de Números Positivos
- Permita que o usuário digite números até que insira um número **negativo**.  
- Some somente os números **positivos** informados.  
- Ao final, exiba o **total**.

---

### 3. Contagem Regressiva
- Solicite um número inteiro **positivo**.  
- Se for negativo ou zero, peça novamente (**com `do...while`**).  
- Faça uma **contagem regressiva até 0** usando **`for`**.

---

### 4. Números Pares de 1 a N
- Peça um número **N** ao usuário.  
- Com **`for`**, exiba todos os números **pares** de **1 até N**.  
- Use um **`if`** dentro do laço para verificar se é par.

---

### 5. Menu Interativo (Switch + Loop)
- Apresente um menu com opções:  
  1. Soma  
  2. Subtração  
  3. Multiplicação  
  4. Sair  
- Use **`while`** para repetir até o usuário escolher **sair**.  
- Dentro do loop, leia **dois números** e faça a **operação escolhida**.

---

### 6. Contar Números Pares e Ímpares
- Solicite **10 números** ao usuário (**usando `for`**).  
- Para cada número, verifique se é **par ou ímpar**.  
- Ao final, exiba a **quantidade de pares e ímpares** digitados.

---

### 7. Sequência de Fibonacci
- Solicite um número **N** para a **quantidade de termos**.  
- Gere a sequência de **Fibonacci** com **`while`** ou **`for`**.  
- Use **`if`** para impedir que **N** seja menor que **1**.

---

### 8. Jogo de Adivinhação
- Gere um número aleatório de **1 a 50**.  
- Use **`do...while`** para permitir tentativas até o usuário acertar.  
- Informe se o número digitado é **maior ou menor** que o número secreto.

---

## 🧑‍💻 Objetivo
Praticar o uso de estruturas de repetição e condicionais, consolidando a lógica de programação por meio de pequenos desafios.
